# Endpoints

| Método | Endpoint | Finalidade |
|---|---|---|
| GET | `/rodovias` | Listar rodovias |
| GET | `/trechos` | Listar trechos |
| GET | `/trechos/{id}` | Consultar um trecho |
| GET | `/trechos/{id}/risco` | Consultar risco |
| GET | `/mapa/riscos` | Consultar dados geográficos |
| POST | `/meteorologia` | Registrar medição |
| POST | `/analises` | Executar análise |
| GET | `/alertas` | Listar alertas |
| POST | `/simulacoes` | Executar cenário |
